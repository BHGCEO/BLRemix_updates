# BLRemix Updates

Releases-only repository for **BisoLabs Remix** — the HDCube4Compact PCSX2
remaster suite. The app checks this repo's latest release once a day
(anonymous GitHub API, ETag-cached) and offers silent in-app updates from
Settings → Updates.

## Assets

- `BisoLabsRemix-Setup-<version>-full.exe` — fresh install (includes the
  HDCube4Compact + face models).
- `BisoLabsRemix-Setup-<version>-update.exe` — code-only upgrade for
  existing installs; never touches `models/`, `cache/`, or
  `gui_settings.json`.

Source code lives in a private repository; this repo carries releases only.
